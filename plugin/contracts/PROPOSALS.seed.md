# PROPOSALS — rule changes queued by per-item retros

> This is the **seed** copied to `<STATE_HOME>/PROPOSALS.md` once, by
> `/drydock:install`. It is part of the plugin package and gets overwritten
> on `/plugin update` — the live file `/drydock:retro` writes to and
> `/drydock:review` walks lives in `<STATE_HOME>` (`~/.drydock` by default),
> never here.

Each entry: the proposed contract/template amendment, the motivating
evidence (item id, artifact), and a suggested diff. Applied or declined
only by the human — in a full `/drydock:retro` sweep or the review pass.
A per-item retro may write here; it may never amend a contract itself.
